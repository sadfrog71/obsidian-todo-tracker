# OpenClaw Hook: obsidian-todo-hook

监听飞书入站消息，自动识别关键词并写入 Obsidian 待办跟踪系统。

## 部署位置

源码部署到 `/Users/mark.ma/.openclaw/hooks/obsidian-todo-hook/`：

```bash
cp -r . ~/.openclaw/hooks/obsidian-todo-hook/
```

## 启用

`~/.openclaw/openclaw.json`：

```json
{
  "hooks": {
    "internal": {
      "enabled": true,
      "entries": {
        "obsidian-todo-hook": {
          "enabled": true
        }
      }
    }
  }
}
```

重启 Gateway：

```bash
openclaw gateway restart
```

## 关键词规则

| 关键词 | 动作 | 目标位置 |
|--------|------|----------|
| `#想法` | 想法记录 | `马克莱莱综合待办/07-想法/想法.md` |
| `#待办` / `待办` / `#todo` | 新增待办（双向写入） | `{分类}/待办.md` + `汇总待办.md` |
| `#日程` / `日程` | 新增日程 | `04-日程沉淀/日程.md` |
| `#进展` / `进展` | 进展记录 | `{匹配项目}/进展.md` |
| `#会议` / `会议` | 会议纪要 | `04-日程沉淀/会议纪要.md` |
| `#备注` / `备注` | 添加备注 | `{匹配项目}/备注.md` |
| `#完成` / `done` | 标记任务完成 | `00-收集箱/已完成记录.md` |
| `#市场`、`#产品`、`#技术` 等内置主题 | 按主题分类 | `0X-{主题}/待办.md` |
| 其他 `#任意主题` + 内容 | 自动创建主题目录 | `08-{主题}/待办.md` |
| `#主题` 后无内容 | 归档 | `00-待归档/待归档.md` |
| 其他任意消息 | 归档 | `00-待归档/待归档.md` |
