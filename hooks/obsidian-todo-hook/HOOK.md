# Obsidian Todo Hook

## 功能

在收到飞书消息时，自动识别关键词并写入 Obsidian 的「马克莱莱综合待办」目录。

## 关键词规则

| 关键词 | 动作 | 目标位置 |
|--------|------|----------|
| `#想法` | 想法记录 | 马克莱莱综合待办/07-想法/想法.md |
| `#任意内容` | 推送待归档 | 马克莱莱综合待办/00-待归档/待归档.md |
| `待办`、`#待办`、`todo`、`#todo` | 新增待办（双向写入） | 马克莱莱综合待办/{AI判断的分类}/待办.md + 汇总待办.md |
| `日程`、`#日程`、`calendar` | 新增日程 | 马克莱莱综合待办/04-日程沉淀/日程.md |
| `进展`、`#进展` | 进展记录 | 马克莱莱综合待办/{匹配项目}/进展.md |
| `会议`、`#会议` | 会议纪要 | 马克莱莱综合待办/04-日程沉淀/会议纪要.md |
| `备注`、`#备注` | 添加备注 | 马克莱莱综合待办/{匹配项目}/备注.md |
| `完成`、`#完成`、`done` | 标记任务完成 | Obsidian 内对应任务 |
| `#市场`、`#产品`、`#技术`、`#售前`、`#项目`、`#管理`、`#个人` | 按主题分类（# 后跟内容时） | `{主题目录}/待办.md` + 汇总待办.md |
| `#主题` 后无内容 | 归档 | 马克莱莱综合待办/00-待归档/待归档.md |
| 其他任意消息 | 归档 | 马克莱莱综合待办/00-待归档/待归档.md |

**优先级**：`#想法` > `#完成` > `#待办`/`#日程` > `#进展`/`#会议`/`#备注` > `#主题分类` > 无匹配（归档到 00-待归档）

## Obsidian 根目录

```
/Users/mark.ma/Documents/obsidian/日常工作/马克莱莱综合待办/
```

## 处理逻辑

1. 解析消息内容，匹配关键词
2. 按优先级选择动作
3. 确定目标文件路径
4. 追加内容（带时间戳）
5. 待办/日程：双向写入分类文件 + 汇总待办.md
6. #主题分类时自动创建缺失目录
7. 静默执行，不打断正常对话
