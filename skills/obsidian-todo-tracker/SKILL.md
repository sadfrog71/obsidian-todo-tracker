# obsidian-todo-tracker SKILL.md

## Overview

当你在 OpenClaw 发送包含关键词的消息时，此技能自动将内容整理到 Obsidian 的「马克莱莱综合待办」文件夹中，并按 AI 判定的分类归档。每天早上 9:30 自动汇总 Obsidian 中的待办事项并发送给你。


## 关键词触发规则

| 关键词 | 动作 | 目标位置 |
|--------|------|----------|
| `#想法` | 想法记录 | 马克莱莱综合待办/07-想法/想法.md |
| `#任意内容` | 推送待归档 | 马克莱莱综合待办/00-待归档/待归档.md |
| `待办`、`#待办`、`todo`、`#todo` | 新增待办（双向写入） | 马克莱莱综合待办/{AI判断的分类}/待办.md + 汇总待办.md |
| `日程`、`#日程`、`calendar` | 新增日程（同步飞书日历） | 马克莱莱综合待办/04-日程沉淀/日程.md + 汇总待办.md |
| `进展`、`#进展` | 进展记录 | 马克莱莱综合待办/{匹配项目}/进展.md |
| `会议`、`#会议` | 会议纪要 | 马克莱莱综合待办/04-日程沉淀/会议纪要.md |
| `备注`、`#备注` | 添加备注 | 马克莱莱综合待办/{匹配项目}/备注.md |
| `完成`、`#完成`、`done` | 标记任务完成 | Obsidian 内对应任务 + 飞书日历（如适用） |

> **汇总待办.md**：每次新增待办或日程时，同时追加到根目录的 `汇总待办.md`。首次发送待办时自动创建该文件。

## 待办分类逻辑（`待办` / `日程` 关键词）

1. **扫描目录结构** — 读取 `马克莱莱综合待办/` 下所有子文件夹作为候选分类
2. **AI 自主判断** — 分析消息内容，判断属于哪个分类（如：售前、项目、管理、技术、个人等）
3. **追加到目标文件** — 如果该分类文件夹下有 `待办.md` 则追加，否则在文件夹根目录创建
4. **默认位置** — 如果无法判断，归入 `00-收集箱/待办.md`

## 完成触发逻辑

当消息包含 `完成`、`#完成`、`done`、或明确指出「XXX 已完成」时：

1. **在 Obsidian 中查找匹配任务** — 搜索 `马克莱莱综合待办/` 下所有 `.md` 文件，找到描述最接近的任务
2. **标记为已完成** — 将 `- [ ]` 改为 `- [x]`，保留原记录
3. **飞书日历同步** — 如果该任务关联了飞书日历事件 ID，同步更新日历事件状态为「已完成」
4. **记录完成时间** — 在任务下方追加 `> ✅ 完成于 {YYYY-MM-DD HH:mm}`

## 每日 9:30 汇总任务

**触发时间**：每天 09:30 Asia/Shanghai

**数据来源**：
- Obsidian：扫描 `马克莱莱综合待办/` 目录下所有 `.md` 文件，提取未完成的 checkbox 任务（`- [ ]` 开头）
- 飞书日历：获取今日 + 未来 7 天日程事件（仅展示尚未过期的）

**汇总逻辑**：
1. 扫描所有子文件夹的 `待办.md` 及散落的 checkbox 任务
2. 获取飞书日历未来 7 天事件
3. 按分类汇总，列出所有未完成待办和即将到来的日程
4. 标注每条的来源文件路径
5. 标记已过期任务（截止时间早于今天）
6. 生成简洁的摘要发送给你

**汇总格式**：

```markdown
# 📋 马克莱莱待办 + 日程汇总

## 📅 即将到来的日程（未来 7 天）
- {日期} {时间} {日程标题}（来源：04-日程沉淀/日程.md）

## 售前
- [ ] {任务1}（来源：01-售前/待办.md）⚠️ 已过期
- [ ] {任务2}（创建于 {日期}）

## 项目管理
- [ ] {任务1}（来源：02-项目管理/待办.md）

## ...

共 {N} 项待办，其中 {M} 项已过期
```

## 自动清理规则

- **过期提醒**：检测 `- [ ]` 任务中包含「截止」「deadline」「过期」等时间描述的，在汇总时标记 ⚠️ 已过期
- **已完成迁移**：已完成的 checkbox 任务（`- [x]`）保留 7 天后由你手动清理，技能不主动删除
- **飞书日历已过期事件**：自动从汇总的「即将到来的日程」中移除

## 执行流程

### 处理消息时
1. 识别关键词类型（#想法/#任意内容/待办/日程/进展/会议/备注/完成）
2. **优先级**：`#想法` > `#任意内容` > 其他关键词
3. 扫描 `马克莱莱综合待办/` 目录结构
4. AI 判断目标分类（或精确匹配项目名）
5. 加载目标文件内容
6. 应用模板格式化（含时间戳）
7. 写入目标文件
8. **待办/日程：双向写入** → 同时写入分类文件和 `汇总待办.md`（首次自动创建）
9. 如为日程，调用飞书日历 API 同步创建事件
10. 向你确认实际写入路径

### 每日汇总时
1. 递归扫描 `马克莱莱综合待办/` 下所有 `.md`
2. 提取所有 `- [ ]` 未完成任务
3. 获取飞书日历未来 7 天事件
4. 按文件夹分类
5. 生成汇总报告
6. 发送给你

### 处理完成触发时
1. 识别完成意图和任务描述
2. 在 Obsidian 中模糊匹配最接近的任务
3. 更新 checkbox 为已完成，追加完成时间
4. 如关联飞书日历 ID，同步更新日历事件
5. 向你确认完成记录

## 飞书 API 集成

- **日历事件创建**：`feishu_calendar_event` → `action=create`
- **日历事件查询**：`feishu_calendar_event` → `action=instance_view` → today + 7 days
- **日历事件更新**：`feishu_calendar_event` → `action=update`
- **任务查询**：`feishu_task_task` → `action=list` → `status=todo`（用于关联参考）
