# Obsidian Todo Tracker

## ⚡ 触发机制（自动激活）

每条飞书消息进入主 agent 后，**先扫描以下关键词**，命中后立即按规则执行归档：

| 关键词 | 触发动作 | 目标位置 |
|--------|----------|----------|
| `#想法` | 想法记录 | `马克莱莱综合待办/07-想法/想法.md` |
| `#待办` / `待办` / `#todo` / `todo` | 新增待办（双向写入） | `{分类}/待办.md` + `汇总待办.md` |
| `#日程` / `日程` / `calendar` | 新增日程（飞书日历同步） | `04-日程沉淀/日程.md` + `汇总待办.md` |
| `#进展` / `进展` | 进展记录 | `{匹配项目}/进展.md` |
| `#会议` / `会议` | 会议纪要 | `04-日程沉淀/会议纪要.md` |
| `#备注` / `备注` | 添加备注 | `{匹配项目}/备注.md` |
| `#完成` / `完成` / `done` | 标记任务完成 | Obsidian 匹配任务 + 飞书日历 |
| `#任意主题`（如 `#市场`、`#产品`、`#技术`，但无具体内容） | 按主题分类 | `{分类}/待办.md` + `汇总待办.md` |
| **# 后面无主题内容**（如 `#待办`、`#备注`、`#进展` 但后面没东西） | 归档 | `马克莱莱综合待办/00-待归档/待归档.md` |
| 其他任意消息 | 归档 | `马克莱莱综合待办/00-待归档/待归档.md` |

**优先级**：`#想法` > `#完成` > `#待办`/`#日程` > `#进展`/`#会议`/`#备注` > `#主题分类`（市场/产品/技术/...） > 无匹配（归档到 `00-待归档`）

**新规则（2026-07-05 马老师确认）**：
- `#` 后跟主题分类词（如 #市场、#产品）→ 写入对应 `0X-主题/待办.md`，AI 自动创建缺失的分类目录
- `#` 后跟内容但无明确主题 → 写入 `00-待归档/待归档.md`
- 完整消息无 `#` 关键词 → 同样写入 `00-待归档/待归档.md`

## 执行流程

1. 扫描消息关键词
2. AI 判断目标分类（扫描 `马克莱莱综合待办/` 子目录作为候选）
3. 读取目标文件当前内容（如不存在则创建）
4. 应用下方模板追加
5. 写入文件
6. 待办/日程 → 双向写入 `汇总待办.md`
7. 日程 → 同步飞书日历
8. 向马老师确认实际写入路径


## 失败处理

- 目录不存在 → 创建
- 文件不存在 → 自动创建
- 飞书日历 API 失败 → 重试 3 次，仍失败则提示
- 多关键词冲突 → 按优先级表取最高
