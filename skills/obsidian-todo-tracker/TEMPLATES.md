# 记录模板

> 路径为相对于 `马克莱莱综合待办/` 的相对路径。AI 根据目录结构动态匹配分类。时间戳统一使用 Asia/Shanghai 时区。

---

## 待办追加模板

追加到 `{分类文件夹}/待办.md`：

```markdown
- [ ] {任务描述}（创建于 {YYYY-MM-DD HH:mm} · 截止 {截止时间（如有）}）
  > {AI 补充的简要说明或背景}
  > 来源：{原始消息摘要}
```

---

## 汇总待办模板（写入 汇总待办.md）

每次新增待办或日程时，同时追加到根目录的 `汇总待办.md`（首次发送待办时自动创建）：

```markdown
- [ ] {任务描述}（[{分类}] · 创建于 {YYYY-MM-DD HH:mm} · 截止 {截止时间（如有）}）
  > {AI 补充的简要说明或背景}
  > 分类来源：{分类文件夹}/{文件名}
```

### 汇总待办.md 文件初始化模板

首次创建时文件头部：

```markdown
# 汇总待办

> 所有待办和日程的统一入口。按时间倒序排列。

## 待办
<!-- 待办列表将追加在此 -->

## 日程
<!-- 日程列表将追加在此 -->

---

*最后更新：{YYYY-MM-DD HH:mm}*
```

## 日程追加模板

追加到 `04-日程沉淀/日程.md`，并同步创建飞书日历事件：

```markdown
## {YYYY-MM-DD} 日程

- [ ] **{日程标题}**
  - **时间**：{YYYY-MM-DD HH:mm} - {结束时间}
  - **地点/链接**：{地点或会议链接}
  - **参与者**：{参与者（如有）}
  - **议题**：{议题摘要}
  - **飞书日历事件 ID**：{创建后填入}
```

## 每日汇总模板

每天 09:30 汇总时使用：

```markdown
# 📋 马克莱莱待办 + 日程汇总

## 📅 即将到来的日程（未来 7 天）
- {日期} {时间} {日程标题}（来源：04-日程沉淀/日程.md）

## {分类名}
- [ ] {任务1}（来源：{分类文件夹}/待办.md）⚠️ 已过期
- [ ] {任务2}（创建于 {日期}）

## {分类名}
- [ ] {任务1}（来源：{分类文件夹}/待办.md）

---

共 {N} 项待办，其中 {M} 项已过期
```

## 飞书日历事件模板（API 级）

创建飞书日历事件时使用：

```json
{
  "summary": "{日程标题}",
  "description": "{议题摘要}\n来源：马克莱莱综合待办/04-日程沉淀/日程.md",
  "start_time": {
    "timestamp": "{Unix timestamp 开始}",
    "timezone": "Asia/Shanghai"
  },
  "end_time": {
    "timestamp": "{Unix timestamp 结束}",
    "timezone": "Asia/Shanghai"
  },
  "location": "{地点或会议链接}"
}
```
